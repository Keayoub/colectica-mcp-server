# v0.2.0 — Convenience tools and composite queries

## What's New

### New MCP tools (Batch 5)

| Tool | Description |
|---|---|
| `server_info` | Returns server version, base URL, transport, resolved auth mode, and live OpenAPI connectivity status. Useful as a first call for LLM orientation. |
| `search_by_text` | Plain-text search wrapper that builds the request body automatically. Accepts `query`, optional `item_types` (DDI URN list), `max_results` (1–1000), and `agency_ids`. Eliminates the need for LLMs to know the raw search body schema. |
| `get_item_summary` | Fetches item history and latest version number concurrently in a single tool call, reducing round trips. Returns `agency`, `id`, `latest_version`, and `history` keys. |

### Internal improvements

- Added `asyncio` import (was missing) to support `asyncio.gather` in `get_item_summary`.
- `_SERVER_VERSION` imported from `__version__.py` into `server.py` for single source of truth.
