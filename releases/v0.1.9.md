# v0.1.9 — Developer tooling & dynamic versioning

## What's new

### Dynamic versioning
- Added `src/colectica_mcp/__version__.py` as the single source of truth for version, author, and description
- `pyproject.toml` now uses `dynamic = ["version"]` with `[tool.hatch.version]` pointing to `__version__.py`
- `src/colectica_mcp/__init__.py` re-exports `__version__`, `__author__`, and `__description__`

### Developer scripts
- **`diagnose.ps1`** — pre-flight diagnostics: checks server file, Python ≥ 3.10, required packages (`mcp`, `httpx`, `python-dotenv`), env vars, `.env` file, and `requirements.txt`; prints ✅/⚠️/❌ sections with exit code
- **`build_pypi.ps1`** — clean → build → smoke-test → optional PyPI publish; supports `-Publish`, `-TestPyPI`, `-SkipInstallTest` switches; uses `uv`

### LLM prompt guidance
- **`PROMPT_INSTRUCTIONS.md`** — prompt templates and quick rules for LLMs using the MCP server: discover operations, execute by `operationId`, chain calls, and short example prompts

### VS Code integration
- `.vscode/launch.json` — two debug configurations: stdio and streamable-http transport
- `.vscode/tasks.json` — tasks: Install dependencies, Run diagnose, Build PyPI package

## Maintenance
- `hosting/.gitignore` — exclude `.azure/` directory (generated by `azd env`)
