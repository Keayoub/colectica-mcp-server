# v0.2.1

## What's New

### FastMCP ASGI Hosting for Azure Functions

`hosting/app/function_app.py` has been rewritten to host the MCP server via FastMCP's native
streamable-HTTP ASGI app rather than a hand-rolled JSON-RPC bridge.  Two compatibility
issues with Azure Functions' `AsgiMiddleware` are resolved by a new `_FastMCPBridge` class:

- **Path prefix** – Azure Functions routes deliver `/api/mcp` but FastMCP mounts at `/mcp`.
  The bridge strips the leading `/api` before forwarding.
- **Lifespan** – `AsgiMiddleware` never emits ASGI lifespan events, so FastMCP's
  `StreamableHTTPSessionManager` never initialises its `anyio` task group.
  The bridge drives the lifespan startup in a background asyncio task on the first request.

### Structured Agent Instructions (`prompt_instructions.md`)

A new `src/colectica_mcp/prompt_instructions.md` file (294 lines, 7 sections) is bundled
with the package and loaded at startup via `_load_instructions()` in `server.py`:

1. Safety Rules
2. Goal → Tool Routing
3. `qualifiedName` Patterns
4. Named Workflows (A–E)
5. Authentication
6. Error Handling
7. Tool Reference (compact)

A `FileNotFoundError` fallback is included for environments where the file is absent.
