# Release Notes — v0.1.7

**Release Date:** May 21, 2026  
**Previous Version:** 0.1.6

---

## Overview

v0.1.7 adds **container deployment** and **AI agent integration** support,
making it straightforward to host both MCP servers as cloud-native HTTPS
services and connect them to AI Foundry, GitHub Copilot, or any agent
framework.

---

## New Features

### Container support for streamable-http transport

- **`Dockerfile`** — Production-ready container image for `colectica-mcp-server`
  - Runs in `streamable-http` mode, exposes port 8000
  - All configuration via environment variables
  - `HEALTHCHECK` built-in (polls `/mcp` endpoint)
- **`docker-compose.yml`** — Full local dev stack
  - `colectica-mcp` → `http://localhost:8000/mcp`
  - `purview-mcp`   → `http://localhost:8001/mcp`
  - `foundry-agent` → AI Foundry agent (waits for both MCP healthchecks)
- **`.env.example`** extended with container, Purview, and AI Foundry variables

### GitHub Copilot Agent with 5 skills

Activate `@ColecticaPurviewAgent` in VS Code Copilot Chat.

| Skill | Scenario |
|---|---|
| `sync-metadata` | Search Colectica → transform DDI items → bulk import to Purview |
| `lineage-propagation` | Relationship matrix → Purview lineage edges |
| `drift-detection` | Missing / stale / orphaned entity detection |
| `tag-governance` | Bidirectional tag ↔ classification sync |
| `cross-system-query` | Natural-language Q&A across both systems |

Files (gitignored per CADO convention — local-only):
- `.github/agents/ColecticaPurviewAgent.md`

- `.github/skills/tag-governance.md`

- **`Dockerfile`** — Deploy to Container Apps, ACI, or any Docker host
- **`requirements.txt`** — `azure-ai-projects>=1.0.0b10`, `azure-identity`
- **`README.md`** — Quick start, env vars, Container Apps + AI Foundry Portal
  deploy steps

## Transport quick reference

| Mode | Command | Use case |
|---|---|---|
| stdio | `colectica-mcp` | VS Code, Claude Desktop, local agents |
| streamable-http | `colectica-mcp --transport streamable-http --host 0.0.0.0` | Docker, Azure Container Apps, AI Foundry |
