Quick launch

Minimal setup for local development and hosted deployments.

Install

python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -e .

Configure

COLECTICA_BASE_URL=https://your-server.colectica.org/
COLECTICA_BEARER_TOKEN=<token>
# or COLECTICA_USERNAME / COLECTICA_PASSWORD

Run

colectica-mcp --transport stdio

colectica-mcp --transport streamable-http --mount-path /mcp
